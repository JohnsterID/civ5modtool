files of Vox Populi's Community Patch (v 139), by the CivFanatics Community Patch Project team
(https://github.com/LoneGazebo/Community-Patch-DLL), released under the GNU General Public License
version 3 with the project's own terms (no resale; do not pass it off as your own). They are VP's
4.17.8 release files (commit 0bbc47c9d of that repository, where git stores them with LF line endings)
in ModBuddy's original CRLF form, kept unchanged as a reference for ModBuddy's project and solution
layout, which only the ModBuddy editor writes. `modbuddy/` holds ModBuddy builds of this project's own
test mods.
